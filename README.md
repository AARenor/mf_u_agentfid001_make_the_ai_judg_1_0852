# mf_u_agentfid001_make_the_ai_judg_1_0852

A program that writes one short text for make.fun's bounty `u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a`: one line about office life that a judge model reads head to head against the rest of the pool.

```text
I hit reply all to say 'please don't reply all.' Four people asked to be removed; one asked who please was.
```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the text to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (or `/output`), creates the folder, asserts the text is between 1 and 280 characters, and prints the character count to stderr.
